[ ] 대괄호 안은 버튼 클릭

### 1. 회원가입 및 로그인

1-1. 회원가입

- 로그인 페이지 진입
- [가입하기 버튼 클릭]
- 이메일, 비밀번호, 닉네임, 모국어 입력
- [회원가입 버튼 클릭]

1-2. 로그인

- 로그인 페이지 자동 이동
- 이메일, 비밀번호 입력
- [로그인 버튼 클릭]
- 메인 페이지 진입

### 2. 실시간 쉐도잉

- 먼저하는 이유는 리포트추출시에 시간이 걸림 + 마이페이지에서 코픽과 쉐도잉 함께 보기 위함

2-1. 메인 페이지

- 쉐도잉 방 목록 확인
- 상단 4개 카테고리 필터 (일상회화, 비즈니스, 뉴스, 여행)
- 각 카테고리 클릭하여 필터링 동작 확인

2-2. 방 생성

- [방 생성 버튼 클릭]
- 테마 선택: 일상회화
- 컨텐츠 선택: 임시컨텐츠
- 방 제목 입력: Meari service
- 비밀번호 입력: 1234
- 최대 인원 설정: 4명
- [방 생성 완료 버튼 클릭]

2-3. 디바이스 세팅

- 마이크 선택 드롭다운 확인
- 카메라 선택 드롭다운 확인
- 화면에 본인 영상 미리보기 확인
- [입장하기 버튼 클릭]

2-4. 쉐도잉 방 대기실 

- 참여자 영상 화면 확인
- 우측 채팅 패널 확인
- 채팅 입력 후 전송 테스트
- [컨텐츠 변경 버튼 클릭]
- 컨텐츠 목록에서 'buy' 임시컨텐츠 선택
- [컨텐츠 변경 확인]
- 마이크 온/오프 버튼 클릭 테스트
- 카메라 온/오프 버튼 클릭 테스트
- 참여자 준비 상태 표시 확인
- [준비 완료 버튼 클릭]
- 모든 참여자 준비 완료 상태 확인

2-5. 쉐도잉 진행

- [쉐도잉 시작 버튼 클릭]
- 1라운드 영상 시청 (자막 표시 확인)
- 1라운드 종료 후 캐릭터 선택 화면 전환
- [캐릭터 선택 버튼 클릭] (예시 캐릭터 A)
- 2라운드 쉐도잉 실습 시작
- 자신의 차례에 대사 발화
- 발화 중 녹음 표시 확인
- 2라운드 완료
- 리포트 분석 중 로딩 화면 (1-2분 소요)
- 분석 완료 알림

여기까지 진행 후 AI 분석하는데 시간이 걸린다는거 설명 후 코픽으로 넘어가기

### 3. 코픽 평가

3-1. 코픽 진입

- [상단 네비게이션 - 코픽 메뉴 클릭]
- 4개 테마 카드 확인 (일상회화, 비즈니스, 뉴스, 여행)

3-2. 테마 선택

- [일상회화 테마 클릭]
- 테마 설명 및 소요 시간 확인
- [평가 시작하기 버튼 클릭]

3-3. 질문 1/5

- 질문 텍스트 확인
- [녹음 시작 버튼 클릭]
- 60초 타이머 카운트다운 시작
- 답변 발화 (20-30초)
- [녹음 중지 버튼 클릭] 또는 자동 종료
- [다음 버튼 클릭]
- 백그라운드 분석 시작

3-4. 질문 2~5

- 동일한 방식으로 질문 2~5 진행
- 각 질문마다 분석 진행률 표시 (2/5, 3/5, 4/5, 5/5)

3-5. 분석 대기

- 로딩 애니메이션
- 분석 진행률 표시 (3/5 완료, 4/5 완료, 5/5 완료)

3-6. 결과 확인

- 분석 완료 화면 전환
- 종합 점수 확인 (예: 75/100, Level 6)
- 세부 점수 확인 (발음 정확도: 80, 유창성: 70, 문법: 75, 어휘력: 72)

3-7. 상세 피드백

- [질문 1 상세보기 클릭]
- 내 답변 텍스트 (STT 결과) 확인
- [내 답변 재생 버튼 클릭]
- 모범 답변 텍스트 확인
- [모범 답변 재생 버튼 클릭]
- 아쉬운 점 확인
- 교정 표현 확인 (잘못된 표현 → 올바른 표현)
- 표현 팁 확인
- 질문 2~5 피드백도 동일하게 확인 가능

3-8. 종료

- [처음으로 돌아가기 버튼 클릭]
- 메인 페이지 이동

### 4. 일일학습 - 단어 학습

4-1. 진입

- [상단 네비게이션 - 일일학습 메뉴 클릭]
- 단어 학습 카드, 문장 순서 맞추기 카드 확인
- 학습 달력 (잔디) 확인

4-2. 단어 학습 시작

- [단어 학습 카드 클릭]
- 랜덤 10개 단어 제공 안내
- [학습 시작 버튼 클릭]

4-3. 단어 학습 (1/10)

- 영어 단어 표시 (예: Confidence)
- 한글 뜻 표시 (예: 자신감)
- 모국어 뜻 표시
- [음성 재생 버튼 클릭]
- 발음 청취
- 예문 및 번역 확인
- [다음 버튼 클릭]

4-4. 단어 2~10

- 동일한 방식으로 진행
- 진행률 표시 (3/10, 5/10, 8/10...)

4-5. 완료

- 완료 메시지 표시
- 선택지: [문장 순서 학습 가기] / [홈으로 이동]
- 달력에 잔디 심어짐 확인 (오늘 날짜 초록색 표시)
- [문장 순서 학습 가기 버튼 클릭]

### 5. 일일학습 - 문장 순서 맞추기

5-1. 시작

- 문장 순서 맞추기 화면 진입
- 총 문제 수 표시 (10문제)
- [학습 시작 버튼 클릭]

5-2. 문제 1 - 정답

- 섞인 단어 블록 표시 (예: ["to", "Nice", "meet", "you"])
- 정답 예시 블러 처리 (예: "Nice to meet you")
- [정답 예시 보기 버튼] 확인
- 단어 블록 순서대로 클릭 (Nice → to → meet → you)
- [확인 버튼 클릭]
- 정답 처리 (초록색 체크, "정답입니다!" 메시지)
- [다음 문제 버튼] 자동 활성화

5-3. 문제 2 - 오답

- 섞인 단어 블록 표시 (예: ["going", "are", "Where", "you", "?"])
- 잘못된 순서로 배열 (You → are → going → Where → ?)
- [확인 버튼 클릭]
- 오답 처리 (빨간색 X, "틀렸습니다" 메시지)
- 단어 블록 리셋
- 올바른 순서로 재배열 (Where → are → you → going → ?)
- [확인 버튼 클릭]
- 정답 처리

5-4. 문제 3~10

- 동일한 방식으로 진행
- 진행률 표시 (3/10, 5/10, 8/10...)

5-5. 완료

- 완료 메시지
- 학습 통계 확인 (정답률, 소요 시간)
- 선택지: [단어 학습으로 이동] / [홈으로 이동]
- 잔디 추가 표시 확인 (진한 초록색 또는 별 표시)
- [홈으로 이동 버튼 클릭]
- 메인 페이지 이동

### 6. 마이페이지

6-1. 쉐도잉 리포트 (마이페이지에서 확인)

- [상단 네비게이션 - 마이페이지 클릭]
- 쉐도잉 기록 탭 진입
- [최근 리포트 클릭]
- 종합 점수 확인 (발음 정확도, 유창성, 억양)
- 문장별 분석 결과 확인
- 발음 오류 부분 하이라이트 확인

6-2. Dashboard

- [상단 네비게이션 - 마이페이지 클릭]
- 좌측 사이드바 확인 (Dashboard, Profile, Settings, Report)
- 쉐도잉 진행 차트 확인
- 코픽 요약 차트 확인
- 일일 활동 히트맵 (잔디) 확인
- 우측 활동 피드 확인

6-3. Profile

- [좌측 사이드바 - Profile 클릭]
- 프로필 정보 확인 (이미지, 닉네임, 이메일, 모국어)
- [개인정보 수정 버튼 클릭]
- 비밀번호 입력 후 [확인]
- [프로필 이미지 클릭] → 이미지 선택 및 업로드
- 닉네임 수정
- 모국어 변경 (한국어/베트남어/영어)
- [저장 버튼 클릭]

6-3. Report

- [좌측 사이드바 - Report 클릭]

쉐도잉 리포트

- 쉐도잉 리포트 목록 확인
- [특정 리포트 클릭]
- 우측 패널에서 상세 확인:
    - 총점, 정확도, 억양
    - 문장별 분석 (예상 문장 vs 인식된 문장)
    - 오류 분석
- [X 버튼] 패널 닫기

코픽 리포트

- [코픽 리포트 탭 클릭]
- 리포트 목록 확인
- [특정 리포트 클릭]
- 상세 확인:
    - 총점, 평균 정확도
    - 문장별 분석 및 피드백
- [X 버튼] 패널 닫기

6-4. Settings

- [좌측 사이드바 - Settings 클릭]
- [자동 재생] 체크박스 ON/OFF
- [글자 크기] 드롭다운에서 선택
- [테마] 드롭다운에서 라이트/다크 선택
