📡 WebSocket API 엔드포인트

📤 클라이언트 → 서버 (Send)

  • /app/room/{roomId}/ready - 준비 상태 토글
  • /app/room/{roomId}/role - 역할 선택
  • /app/room/{roomId}/role/release - 역할 해제
  • /app/room/{roomId}/chat - 채팅 메시지 전송

📥 서버 → 클라이언트 (Subscribe)

  • /topic/room/{roomId}/state - 방 상태 변경 알림
  • /topic/room/{roomId}/chat - 채팅 메시지 수신
