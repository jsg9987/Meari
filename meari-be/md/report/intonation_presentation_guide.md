## 📚 예상 질문 & 답변

### Q1: "왜 librosa 대신 Parselmouth를 선택했나요?"

**답변:**
```
"좋은 질문입니다. 세 가지 이유가 있습니다.

첫째, Parselmouth는 Praat 기반으로,
전 세계 음성학자들이 사용하는 검증된 도구입니다.

둘째, Valid ratio가 60.8%에서 68.8%로 향상되어

셋째, 음성학적으로 검증된 알고리즘을 사용하므로
신뢰성이 높습니다."
```

### Q2: "Z-score 정규화가 왜 필요한가요?"

**답변:**
```
"화자 간 Pitch 범위 차이를 제거하기 위해서입니다.

예를 들어, 여성은 평균 216Hz, 남성은 평균 195Hz입니다.
정규화 없이 비교하면 절대값 차이 때문에 점수가 낮게 나옵니다.

하지만 Z-score 정규화를 하면,
각 화자의 평균을 0으로, 표준편차를 1로 맞춰서
상대적인 억양 패턴만 비교할 수 있습니다.

이렇게 하면 여성과 남성을 공정하게 평가할 수 있습니다."
```

### Q3: "DTW가 정확한가요? 다른 방법은 없나요?"

**답변:**
```
"DTW는 시계열 데이터 비교의 표준 알고리즘입니다.

장점은 발화 속도 차이를 자동으로 보정해준다는 것입니다.
빠르게 말하거나 천천히 말해도,
억양 패턴이 같으면 같은 점수를 줍니다.

대안으로 Correlation이나 HMM도 있지만,
DTW가 가장 직관적이고 효과적입니다.

다만, DTW distance를 점수로 변환하는 공식은
저희가 Pitch 통계 기반으로 개선했습니다."
```

### Q4: "실시간으로 분석이 가능한가요?"

**답변:**
```
"네, 가능합니다.

3초 오디오를 분석하는 데 약 0.5~1초 정도 걸립니다.
Parselmouth가 빠르고, DTW도 효율적인 알고리즘이므로
실시간 분석에 문제가 없습니다.

실제로 저희 서비스에서는
사용자가 녹음을 마치면 즉시 결과를 보여줍니다."
```

## 🎓 기술 용어 설명 (백업)

### Pitch (F0, Fundamental Frequency)
```
성대의 진동 주파수로, 목소리의 '높낮이'를 나타냅니다.
Hz(헤르츠) 단위로 측정하며,
높을수록 높은 목소리, 낮을수록 낮은 목소리입니다.

예: 여성 평균 200Hz, 남성 평균 120Hz
```

### DTW (Dynamic Time Warping)
```
길이가 다른 두 시계열 데이터를 비교하는 알고리즘입니다.
시간 축을 최적으로 정렬해서 가장 작은 거리를 찾습니다.

음성 인식, 제스처 인식 등에 널리 사용됩니다.
```

### Z-score 정규화
```
데이터를 평균 0, 표준편차 1로 변환하는 표준화 방법입니다.
서로 다른 스케일의 데이터를 비교할 때 사용합니다.

공식: z = (x - mean) / std
```

### Valid Ratio
```
Pitch 추출 시 유효한 값의 비율입니다.
무성음(ㅅ, ㅎ 등)은 Pitch가 없으므로 NaN으로 반환됩니다.

Valid ratio가 높을수록 Pitch 추출 품질이 좋습니다.
```
