================================================================================
                    WebRTC 화상통화/음성통화 API 명세서
================================================================================

방 관리 API (프론트엔드 메인 사용) - 2개
  1. POST /api/v1/rooms/{roomId}/webrtc/enter - 방 입장 (비밀번호+토큰)
  2. DELETE /api/v1/rooms/{roomId}/webrtc/leave - 방 퇴장

OpenVidu API (관리자/테스트용) - 6개
  3. POST /api/v1/openvidu/sessions - 세션 생성
  4. POST /api/v1/openvidu/sessions/{sessionId}/connections - 토큰 생성
  5. GET /api/v1/openvidu/sessions/{sessionId} - 세션 정보 조회
  6. GET /api/v1/openvidu/sessions - 활성 세션 목록
  7. DELETE /api/v1/openvidu/sessions/{sessionId} - 세션 종료
  8. DELETE /api/v1/openvidu/sessions/{sessionId}/connections/{connectionId} - 연결 강제 종료



================================================================================
1. 방 입장
================================================================================

### 방 입장 시 비밀번호와 정원을 확인한 후 WebRTC 토큰을 발급합니다.

### 기본정보

| 메서드 | URL | 인증방식 |
| --- | --- | --- |
| POST | /api/v1/rooms/{roomId}/webrtc/enter | 인증 인가 O |

# Path Parameter

| 파라미터 | 타입 | 설명 | 필수 |
| --- | --- | --- | --- |
| roomId | Long | 방 ID | O |

# Request Header

| 헤더 이름 | 값 | 설명 | 필수 |
| --- | --- | --- | --- |
| Content-Type | application/json |  | O |
| Authorization | Bearer {accessToken} | JWT 인증 토큰 | O |

# Request Body

| key명 | 타입 | 설명 | 필수 |
| --- | --- | --- | --- |
| password | string | 방 비밀번호, 공개방은 생략 | X |
| member_id | number | 사용자 ID | O |
| nickname | string | 서비스 내 활동명 | O |

```json
{
    "password": "1234",
    "member_id": 1,
    "nickname": "김철수"
}
```

# Response Body

```json
{
    "success": true,
    "data": {
        "room_id": 1,
        "session_id": "room_1",
        "token": "wss://your-openvidu-server:443?sessionId=room_1&token=tok_...",
        "connection_id": "con_XYZ789abc",
        "current_people": 1,
        "max_people": 2
    },
    "error": null
}
```

# Error(예외 상황)

| HTTP Code | Error Code | 설명 |
| --- | --- | --- |
| 403 | `INVALID_ROOM_PASSWORD` | 방 비밀번호가 일치하지 않습니다. |
| 404 | `NOT_FOUND_ROOM` | 존재하지 않는 방입니다. |
| 409 | `ROOM_FULL` | 방 정원이 초과되었습니다. |
| 409 | `ROOM_ALREADY_STARTED` | 이미 학습이 시작된 방입니다. |
| 409 | `ROOM_ALREADY_CLOSED` | 이미 종료된 방입니다. |
| 500 | `OPENVIDU_SESSION_CREATE_FAILED` | OpenVidu 세션 생성에 실패했습니다. |
| 500 | `OPENVIDU_CONNECTION_CREATE_FAILED` | OpenVidu 연결(토큰) 생성에 실패했습니다. |
