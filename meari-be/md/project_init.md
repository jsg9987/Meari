```
📋 프로젝트: 실시간 한국어 쉐도잉 및 AI 발음 평가 서비스
1. 프로젝트 개요
서비스 명칭: 4인 준실시간 한국어 쉐도잉 및 AI 평가 서비스

핵심 목표: 다국어 사용자를 대상으로 실시간 화상 환경에서 한국어 콘텐츠를 쉐도잉하고, AI를 통해 발음을 정밀 분석 및 피드백하는 학습 플랫폼

기술 특이사항: 화상 및 음성은 실시간 스트리밍되나, 발음 분석을 위한 녹음은 브라우저에서 자막 타임스탬프에 맞춰 개별 녹음 후 서버에 업로드하는 방식

2. 주요 기능 모듈
🔐 인증 및 사용자 관리 (Auth & User)
회원 시스템: 이메일 기반 로그인/회원가입 및 프로필 관리(닉네임, 사진).

글로벌 대응: 사용자의 모국어 선택 기능 (다국어 UI 대응).

학습 이력: 코칭 리포트 및 쉐도잉 리포트 조회(점수 및 피드백).

📖 사전 학습 및 보조 (Study & History)
문장 순서 맞추기: DB의 문장을 무작위로 섞어 올바른 문장 구조 학습.

단어 학습: 주제별 주요 단어 빈칸 채우기 및 외부 API(국립국어원 등) 연동 사전 검색.

🗣️ Kopic 세션 (AI 대화 및 평가)
AI 대화진행: 특정 테마/상황을 선택하여 AI와 대화 수행.

실시간 피드백: AI가 대화 내용을 분석하여 즉각적인 피드백 및 종합 점수 산출.

🎥 쉐도잉 세션 (Shadowing - Core)
이 서비스의 핵심 모듈로, 4인 참여형 화상 학습 환경을 제공합니다.

방 관리: 테마별 방 검색, 생성, 대기 및 입장(비밀번호 가능).

상호작용: 실시간 화상/음성 채팅 및 텍스트 채팅.

쉐도잉 프로세스:

콘텐츠 선택: 학습할 영상 및 캐릭터 선택.

라운드 진행: 영상 자막과 역할별 타임스탬프에 맞춰 사용자별 문장 발화.

녹음 및 업로드: 브라우저에서 녹음된 데이터를 서버로 전송하여 AI 분석 요청.

종합 평가: 발음의 정확도, 유창성, 억양 등을 분석하여 시각화된 리포트 제공.

🤖 AI 분석 모듈 (AI Analysis)
발음 평가: 음성 데이터를 분석하여 정확도, 속도, 억양 등 다각도 평가.

리포팅: 분석 결과를 그래프 및 수치로 변환하여 사용자에게 제공.

3. 핵심 데이터 흐름 (Workflow)
사용자: 학습하고 싶은 영상 방에 입장하여 역할을 배정받음.

시스템: 동영상 재생과 함께 자막 데이터를 브라우저에 동기화.

사용자: 본인 차례에 맞춰 발화 (브라우저가 해당 타임스탬프 구간을 녹음).

시스템: 녹음된 파일을 AI 서버로 전송하여 분석 수행.

결과: 세션 종료 후 사용자별 개인별 맞춤 리포트 생성 및 저장.
```

# 2. 상세 기술 스택(Tech Stack)
- Backend: Java 21, Spring Boot 3.5.9, Spring Data JPA, Spring Security(JWT + Redis), WebSocket(STOMP), WebRTC(COTURN, Kurento(어렵지 않고 유용하다면 추가))
- Frontend: React, TailwindCSS, Zustand
- AI 서버(gpu ec2): FastAPI, Wav2Vec 2.0 기반 음소 분석 모델 + 기능들
- DB: PostgreSQL(+ JSONB 활용), Redis
- Messaging: RabbitMQ(Spring Boot <-> FastAPI 비동기 통신) -> 고민해보고 직접 내장할 것인지 결정 필요
- Infrastructure: AWS(EC2, S3, CloudFront), Docker, Nginx, Jenkins, GitLab

# 3. DB 설계 및 전략
- JSONB: 분석 결과를 JSONB 타입에 문장별 분석 정보를 통째로 저장하려고 고려 중
- Redis: 실시간 상태 데이터나 실시간 쉐도잉 세션(방정보, 라운드1, 실시간 정보....)를 저장해서 RDBMS가 아닌 Redis에서 빠르게빠르게 처리
- 파일 저장 전략: 모든 미디어 파일을 S3에 저장하려함, 보안을 위해 Presigned URL을 사용한다. => 모두 S3에 저장하는 것이 좋을지 고민 필요
